System Help Guide

How To Use This System

  1. Login with your assigned username and password.
  2. Open Reservations and add new guest reservation details with a unique reservation number.
  3. Use Find Reservation to display full booking details for a guest.
  4. Open Billing and create an invoice using reservation number, room rate, nights, and charges.
  5. Record guest payments and monitor status as PENDING, PARTIAL, or PAID.
  6. Open an invoice and click Print Bill to generate a printable bill for the guest.
  7. Use Logout when changing users, or Exit when ending the work session.

Tips For Staff

  • Always verify check-in and check-out dates before saving a reservation.
  • Use the Refresh buttons to load the latest records.
  • If you get an error message, correct the highlighted input and submit again.
  • Do not share login credentials with unauthorized users.
